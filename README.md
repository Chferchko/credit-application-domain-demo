# Демо модуля кредита

- граница транзакции в `CreateCreditHandler`;
- откат транзакции при ошибках;
- разделение ожидаемых бизнес-отказов и неожиданных технических ошибок;
- контракты репозиториев и gateway;
- доменные сущности и value object для кредита, клиента и товаров в заявке.

Основной файл для обсуждения транзакции и обработки ошибок:

`src/Credit/Application/CreditCreation/CreateCreditHandler.php`

## Состав

В репозиторий включены только две исходные директории модуля:

- `Credit/Application`
- `Credit/Domain`

Инфраструктурные реализации, адаптеры базы данных и общие value object из `Core` намеренно не включены.
